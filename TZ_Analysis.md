## Реализованный функционал

### ✅ Полностью реализовано

**Управление печатью:**
- Загрузка G-code файлов на принтер
- Запуск/Пауза/Возобновление/Отмена печати
- Промежуточный статус `awaiting_removal` после завершения печати
- Подтверждение снятия детали со стола

**Уведомления в браузере:**
- Notification API - уведомления при ошибках принтера
- Визуальное выделение карточек с ошибками (CSS)
- Фильтр "Только ошибки" на дашборде

**Учёт расходников:**
- Поле `nozzle_diameter` для каждого принтера (0.2-1.0 мм)
- Отображение диаметра сопла на карточке принтера
- Автоматическое списание материала с катушки при печати
- История расхода материала (SpoolHistory)

**Обслуживание:**
- Типы обслуживания: сопло, ролики, экструдер
- Учёт рабочих часов принтера
- API для получения предстоящего ТО

### ❌ НЕ реализовано

| Функция | Приоритет | Описание |
|---------|-----------|----------|
| Звуковые уведомления | Низкий | Web Audio API для звука при ошибках |
| Email-уведомления | Средний | SMTP для отправки об ошибках и ТО |
| Telegram-бот | Средний | Уведомления через Telegram |
| Журнал событий | Низкий | История всех статусов принтеров |
| Автоочередь печати | Низкий | Автоназначение задач на свободные принтеры |
